Civil Service Examination (CSE) Reviewer Application
Project Overview
This project is an interactive web-based reviewer application designed to help examinees prepare for the Philippine Civil Service Examination (Professional Level). It features a robust database of hundreds of carefully curated questions structured into multiple full-length mock exams, simulating the actual testing experience while providing valuable study aids.

Features
  - Extensive Question Database: Contains five complete mock exams (Books 1 through 5), offering extensive practice material.

  - Comprehensive Coverage: Questions span all major CSE subtests, including:

    - Verbal Ability (Vocabulary, Grammar and Correct Usage, Paragraph Organization, Reading Comprehension)

    - Numerical Ability (Numerical Reasoning, Problem Solving, Math Operations)

    - Analytical Ability (Analogy and Logic, Syllogisms, Word Associations)

    - General Information (Philippine Constitution, Government Initiatives, Environmental Issues, Current Events)

  - Interactive Study Tools: Every question includes a hint to guide the user and a detailed step-by-step explanation to reinforce learning after answering.

  - Dynamic Formatting: Built to support dynamic choice randomization. Reading passages are embedded directly into connected questions so they remain completely coherent even when the exam order is shuffled.

  - Clean UI Rendering: Supports HTML tags within the question text to accurately display mathematical formulas, special characters (like the Philippine Peso sign), and underlined words for vocabulary tests.

Technologies Used
  - HTML5: For structuring the application interface.

  - CSS3: For responsive design and styling.

  - JavaScript (ES6): For the core application logic, event handling, and managing the questionsDatabase object.

Getting Started
Prerequisites
You only need a modern web browser (Google Chrome, Mozilla Firefox, Safari, or Microsoft Edge) to run this application. No backend server or database installation is required.

Installation and Setup
1. Clone this repository to your local machine using standard git commands, or download the ZIP file and extract it.

2. Navigate to the project folder.

3. Open the index.html file directly in your web browser.

Project Structure
  - index.html: The main markup file containing the user interface.

  - style.css: Contains all the styling rules for the application.

  - script.js: Contains the application logic, user interactions, and the questionsDatabase JSON object which holds all the arrays for Book 1 through Book 5.

Usage
Upon launching the application, select which "Book" or mock exam you wish to take. Read each question carefully, utilize the hint button if you get stuck, and review the detailed explanations provided after confirming your answer to maximize your review session.
